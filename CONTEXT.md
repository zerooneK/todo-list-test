# Tasks

A personal task list for one person. The goal is a calm, uncluttered tool
for tracking what needs doing, not a shared or collaborative product.

## Language

**Task**:
A single thing that needs doing. Identified by its text, its state, and when
it was created.
_Avoid_: Todo, item, card, reminder

**Task list**:
The full set of tasks, in the order they were added.
_Avoid_: Todo list, backlog, queue

**Open task**:
A task not yet marked done.
_Avoid_: Active todo, pending item

**Done task**:
A task the person has marked finished. Kept, not deleted, so history survives.
_Avoid_: Completed todo, archived item, checked item

**View**:
Which subset of the task list is currently shown — all tasks, only open
tasks, or only done tasks.
_Avoid_: Filter, tab, mode

**Clear done**:
Sweep away every done task at once. Offered as a single deliberate action,
not an automatic cleanup.
_Avoid_: Clear completed, purge, bulk delete

**Backup**:
A dated copy of the whole task list, written to this computer once a day and
also on demand. The safety net for browser-held tasks.
_Avoid_: Save, export, sync, archive

**Restore**:
Put the task list back from a backup, replacing whatever is there now.
_Avoid_: Undo, import, recover

**Theme**:
The calm visual style the person is looking at — light or dark. The person
picks it with a small toggle and the app remembers that choice.
_Avoid_: Colour scheme, skin, mode, appearance
